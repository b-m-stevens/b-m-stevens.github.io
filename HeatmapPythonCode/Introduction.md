Two sets of python code (one for all crashes and one for VRU crashes) were developed to create a heatmap that shows clusters of crashes as well as the transit stop locations for visual representation of the system. The code takes .csv files for transit stops and crashes based on their location as input. This code projected all the latitude and longitude data into WGS84 projection for cohesion. The python code for all crashes is listed in the first section, followed by the python code for VRU crashes.
