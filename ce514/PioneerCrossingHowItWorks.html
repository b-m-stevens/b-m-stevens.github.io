Pioneer Crossing How It Works Page

   

National Water Model Forecasting Application

   

Updated: 24 February 2025

This page is intended to describe how the Pioneer Crossing page works. Pioneer Crossing is a model that draws data from the National Weather Service Flow Prediction Service to formulate future flow predictions for the rivers that cross the trail used by the LDS Pioneers in Wyoming and Utah. This page then interprets the flow data and tells the user (you!) if the stream flows are safe to cross on the date of your crossing. Check back regularly as flow predictions are subject to change. This web application retrieves National Water Model short-range forecasts using the NOAA NWPS API.

How The Application Works

   

This web application retrieves National Water Model short-range forecasts using the NOAA NWPS API.

     

1)The user enters a Reach ID into the input box above, which is a unique identifier for a river segment.

   

2)The application then makes a request to the NOAA API for the forecast data associated with that Reach ID.

   

3)The retrieved data (time and streamflow values) is then displayed in a table and visualized in a chart using Chart.js.

      

4)If an error occurs during the API call or data processing, an alert message is displayed to inform the user.

   

The API endpoint used is: `https://api.water.noaa.gov/nwps/v1/reaches/{reachId}/streamflow?series=short_range`.  The `{reachId}` portion is replaced with the Reach ID entered by the user.

   

The code first fetches the data from the API.  It then parses the JSON response and extracts the timestamps and flow values.  These values are then used to populate the table and create the chart. The chart is a line graph showing the streamflow over time.

Using Javascript, the webpage then defines markers for each of the stream locations that could be crossed. The map is created, and the function "getForecast()" fetches the forecast when a marker is clicked on. Finally, the shapefile with the Pioneer trail is loaded onto the map from a Hydroshare resource.
