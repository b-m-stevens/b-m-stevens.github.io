NWM Pioneer Crossing Page

This page is intended to describe how the Pioneer Crossing page works. Pioneer Crossing is a model that draws data from the National Weather Service Flow Prediction Service to fomrulate future flow predictions for the rivers that run through [Green River, WY]. This page then interprets the flow data and tells the user (you!) if the stream flows are safe to cross on the date of your crossing. Check back regularly as flow predictions are subject to change.
